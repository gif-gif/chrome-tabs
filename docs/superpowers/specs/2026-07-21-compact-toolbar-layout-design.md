# Chrome Tab Manager 紧凑工具栏布局设计

- 日期：2026-07-21
- 状态：待用户审阅书面规格
- 选定方案：方案 A——两行紧凑布局
- 适用页面：Chrome Extension Side Panel
- 技术栈：React + Vite + TypeScript + CSS

## 1. 背景与目标

当前 Side Panel 工具栏由计数行、语言/视图控件以及独立筛选行组成，纵向空间占用较大。此次优化需要在不牺牲高频操作可达性、状态可读性、国际化和无障碍能力的前提下，将工具栏压缩为两行：

1. 第一行：标签计数、标签筛选、语言、全局脱敏、分组折叠/展开。
2. 第二行：搜索框、列表视图、分组视图。

向下滚动时，第一行继续按现有渐进动画淡出并收起；第二行整体保持吸顶，搜索和视图切换始终可用。

## 2. 范围

### 2.1 本次包含

- 将“全部 / 当前窗口 / 活动标签”改为紧凑图标筛选组并移动到第一行计数右侧。
- 选中筛选项显示“图标 + 文字”，未选中项只显示图标。
- 为筛选按钮提供中英文 tooltip 和无障碍名称。
- 将语言 `<select>` 替换为 32px 地球图标按钮及弹出语言菜单。
- 将分组“折叠 / 展开”文字按钮改为 32px 图标按钮。
- 将“列表 / 分组”视图切换改为两个 32px 图标按钮并移到搜索框右侧。
- 向下滚动时保留完整搜索行，包括搜索框、列表按钮和分组按钮。
- 调整紧凑工具栏的响应式布局、渐进收起高度和动画距离。
- 保持中文、英文和浏览器语言自动模式的完整国际化。
- 保持键盘、焦点、ARIA、Reduced Motion 和现有状态持久化行为。

### 2.2 本次不包含

- 新增语言。
- 改变筛选、搜索、列表/分组的业务逻辑。
- 改变标签页脱敏、关闭、切换或实时同步逻辑。
- 新增扩展权限、host permissions、第三方图标库或动画依赖。
- 改变 Side Panel 关闭按钮和二次确认逻辑。

## 3. 信息架构与布局

### 3.1 第一行：紧凑辅助工具栏

第一行严格保持单行且不换行，逻辑顺序为：

```text
[标签计数] [全部] [当前窗口] [活动标签] [弹性空白] [语言] [全局脱敏] [折叠/展开]
```

其中：

- 标签计数可收缩，空间不足时使用单行省略号。
- 三个筛选按钮不可换行。
- 操作按钮组不可收缩，每个按钮为 32px。
- 分组折叠/展开按钮只在分组模式且存在可显示分组时出现。
- 极窄宽度下优先压缩标签计数；选中筛选文字允许设置最大宽度并省略，但图标和选中态必须保留。
- 第一行整体属于现有 `toolbar-auxiliary` 区域，会随滚动渐隐和收起。

### 3.2 第二行：常驻搜索行

第二行逻辑顺序为：

```text
[搜索框 flex: 1] [列表视图图标] [分组视图图标]
```

要求：

- 搜索框使用 `flex: 1` / `min-width: 0` 占用全部剩余空间。
- 列表和分组按钮固定为 32px，不压缩。
- 搜索框与两个视图按钮属于同一常驻吸顶行。
- 搜索输入仍为现有受控输入，不因布局或滚动重建 DOM，不丢失输入内容、选区或焦点。
- 原有独立筛选标签行被删除，不再占据第三行空间。

## 4. 组件与交互设计

### 4.1 标签筛选组

筛选项及图标语义：

| 值 | 中文显示 | 英文显示 | 图标语义 |
| --- | --- | --- | --- |
| `all` | 全部 | All | 标签集合/多标签 |
| `current-window` | 当前窗口 | Current window | 浏览器窗口 |
| `active` | 活动标签 | Active tabs | 活动状态/高亮标签 |

交互规则：

- 使用 `role="group"` 和本地化的组名称。
- 每个按钮使用 `aria-pressed` 表示选中状态。
- 选中项显示 SVG 图标和可见文字。
- 未选中项只显示 SVG 图标。
- 所有按钮始终提供完整 `aria-label` 和 `title` tooltip。
- 选中项使用主题色文字/图标、浅主题背景和轻量边框或阴影。
- 点击后只改变 `filter`，不重置搜索、语言、视图、脱敏或折叠状态。

### 4.2 语言按钮与菜单

语言选择控件从原有 `<select>` 改为受控弹出菜单：

- 触发按钮：32px 地球 SVG 图标。
- 按钮属性：`aria-haspopup="menu"`、`aria-expanded`、本地化 `aria-label` 和 `title`。
- 菜单位置：按钮下方、与按钮右边缘对齐；保持在 Side Panel 可视范围内。
- 菜单项：
  - 自动（浏览器语言） / Auto (browser language)
  - 中文
  - English
- 菜单使用单选语义（`menuitemradio` 或等价的可访问单选菜单模式）表达当前选择。
- 当前选项显示勾选标记。

打开和关闭：

- 点击地球按钮打开或关闭菜单。
- 打开后将焦点移入当前选中的菜单项；若无法定位则聚焦第一项。
- `ArrowUp` / `ArrowDown` 在菜单项间移动；`Home` / `End` 跳到首尾。
- `Enter` / `Space` 选择当前项。
- `Escape` 关闭菜单并将焦点返回地球按钮。
- 点击菜单外部关闭菜单；若关闭源是普通鼠标点击，不强制抢回焦点。
- 选择语言后保存原有语言偏好、关闭菜单并将焦点返回地球按钮。
- 语言菜单打开或菜单/触发按钮持有焦点时，第一行不得因滚动进入 compact 隐藏状态。

菜单实现使用 React 状态、DOM ref 和事件处理，不依赖第三方弹窗或菜单库。

### 4.3 全局脱敏按钮

- 保留现有眼睛/划线眼睛 SVG 图标和业务行为。
- 统一使用 32px 圆形图标按钮外观。
- 保留现有中英文 `aria-label`。
- 新增或保留对应 `title` tooltip。
- 不增加额外文字。

### 4.4 分组折叠/展开按钮

按钮仅在 `viewMode === 'domain'` 且存在显示分组时出现。

- 当前存在展开分组时：显示“向上双箭头/收起”SVG，操作含义为折叠所有分组。
- 所有分组均已折叠时：显示“向下双箭头/展开”SVG，操作含义为展开所有分组。
- 按钮固定 32px，不显示文字。
- 使用现有国际化文案作为 `aria-label` 和 `title`。
- 保持现有一键折叠/展开业务逻辑。

### 4.5 视图切换组

- 使用两个并列 32px 图标按钮：列表 SVG、分组/网格 SVG。
- 使用 `role="group"` 和本地化组名称。
- 每个按钮使用 `aria-pressed`。
- 选中项使用主题色和浅主题背景；未选中项仅使用中性色图标。
- 两个按钮始终提供本地化 `aria-label` 和 `title` tooltip。
- 切换视图继续触发原有偏好保存，不改变搜索和筛选状态。
- 分组按钮选中后，第一行按现有条件显示折叠/展开按钮。

## 5. 图标系统

正式界面不使用 Unicode 字符或 Emoji。扩展现有内联 SVG `Icon` 组件，新增语义图标：

- 多标签/全部
- 浏览器窗口
- 活动标签
- 地球
- 列表
- 分组/网格
- 全部折叠
- 全部展开
- 勾选

图标规范：

- 默认视觉尺寸 18px。
- 统一 `currentColor`、2px 描边、圆角端点和连接点。
- 统一 24×24 `viewBox`。
- 图标自身 `aria-hidden="true"`，可访问名称由按钮提供。
- 不引入图标字体、图片资源或第三方运行时依赖。

## 6. 响应式规则

### 6.1 常规宽度

- 第一行所有控件单行显示。
- 标签计数与筛选组相邻。
- 操作按钮组靠右。
- 第二行搜索框占据绝大部分宽度。

### 6.2 窄宽度

- 不再在 420px 断点把工具栏拆成两行。
- 标签计数设置 `min-width: 0`、可收缩和省略号。
- 筛选选中文字设置合理 `max-width` 和省略号。
- 未选中的筛选按钮保持 32px。
- 操作按钮和视图按钮保持 32px 点击区域。
- 搜索框允许收缩，但必须保留搜索图标、输入区和清除按钮。
- 不产生页面级横向滚动。

### 6.3 极窄宽度

当空间继续不足时，收缩顺序为：

1. 标签计数文字。
2. 选中筛选项文字最大宽度。
3. 搜索输入区域。

任何情况下不隐藏筛选图标、语言、全局脱敏和视图切换的核心点击目标。

## 7. 滚动与动画

延续现有 `useStickySearchProgress` 架构：

- rAF 直接更新 `--sticky-search-progress`，避免整个 App 和标签列表逐帧 React 重渲染。
- React 状态只在跨越 compact 阈值时更新无障碍和交互语义。
- 第一行随进度逐渐降低透明度、向上移动并收起高度。
- 第二行完整保留并吸顶，包括搜索框和两个视图按钮。
- 因删除独立筛选行，滚动映射距离从现有 112px 调整为与新第一行高度匹配的较短距离；最终值通过实现和视觉验证确定，目标范围为 56–72px。
- 向上滚动按实际 `scrollTop` 反向恢复。
- 第一行内部控件或语言菜单获得焦点时暂停收起，并将视觉进度恢复为展开状态；焦点离开后按最新 `scrollTop` 恢复。
- 搜索框和视图切换按钮获得焦点不需要强制展开第一行。

### 7.1 Reduced Motion

当 `prefers-reduced-motion: reduce` 时：

- 取消明显位移和渐变动画。
- 使用 compact 阈值直接切换第一行展开/隐藏语义状态。
- 搜索行始终保持可见。
- 不改变键盘焦点和控件可用性。

## 8. 状态与持久化

保持现有偏好持久化范围：

- `globalMasked`
- `viewMode`
- `language`

筛选 `filter`、搜索 `query` 和语言菜单开关状态不新增持久化。

工具栏重排不得改变以下状态：

- 搜索内容和焦点
- 当前筛选
- 当前视图
- 折叠的窗口/域名分组
- 全局和单 Tab 脱敏
- 手动语言偏好
- 加载、错误、操作中和操作错误状态

## 9. 无障碍要求

- 所有图标按钮必须有本地化 `aria-label`。
- 所有需要悬停提示的按钮必须有本地化 `title` tooltip。
- 选项型按钮使用 `aria-pressed` 或菜单单选语义。
- 语言按钮正确维护 `aria-expanded`。
- 菜单支持键盘导航、Escape 关闭和合理的焦点返回。
- 可见焦点环必须清晰，不得被 `overflow: hidden` 裁切。
- 被 compact 隐藏的第一行继续使用 `aria-hidden`、`visibility: hidden` 和 `pointer-events: none`，避免不可见控件进入键盘焦点序列。
- 颜色和选中状态不能成为唯一信息来源；图标、文字、ARIA 状态共同表达当前状态。

## 10. 国际化

复用现有中英文文案，并为新增 tooltip/短视觉标签补充必要翻译键。默认语言规则保持：

1. 支持的浏览器语言使用对应语言。
2. 不支持的浏览器语言回退英文。
3. 用户可手动选择自动、中文或英文。

不得在生产组件中硬编码面向用户的中文或英文字符串。

## 11. 测试与验收标准

### 11.1 组件行为

- 三个筛选按钮都有图标；仅选中项显示可见文字。
- 筛选点击正确改变过滤结果，搜索内容保持不变。
- 所有筛选按钮具有正确 `aria-pressed`、`aria-label` 和 `title`。
- 地球按钮打开语言菜单，当前语言项被标记。
- 语言菜单支持点击选择、键盘导航、Escape、点击外部关闭和焦点返回。
- 语言选择仍更新界面语言并保存偏好。
- 全局脱敏和分组折叠按钮为图标按钮，业务行为不变。
- 列表/分组按钮位于搜索行，切换行为和持久化不变。
- 搜索行在 compact 状态下完整保留。

### 11.2 滚动与状态

- 第一行在滚动过程中渐隐、上移、收起；搜索行不被隐藏。
- 向上滚动完整恢复第一行。
- 连续滚动中不逐帧重新渲染完整 App。
- 第一行或语言菜单聚焦时暂停收起。
- 搜索框和视图切换聚焦时仍允许第一行收起。
- 搜索输入 DOM、内容和焦点在滚动往返后保持。
- 原有筛选、视图、折叠、脱敏、语言、加载、错误和 pending 状态在滚动往返后保持。

### 11.3 CSS 与响应式契约

使用 `css-tree` 对具体 selector、media 和 declaration 进行精确检查：

- 第一行不换行。
- 标签计数可收缩和省略。
- 图标按钮尺寸为 32px。
- 搜索行使用 flex，搜索框可伸缩。
- 视图按钮不会被 compact 隐藏。
- 420px 下工具栏仍为单行第一行，不回退到旧两行布局。
- Side Panel 不产生横向滚动。
- Reduced Motion 规则正确。

### 11.4 回归验证

必须通过：

```bash
npm test
npm run lint
npm run build
```

生产构建继续通过 `build/validateDist.ts` 校验，不新增权限、远程资源或不安全 CSP。

## 12. 完成定义

满足以下条件才视为完成：

- 两行紧凑布局与本文一致。
- 第一行筛选和操作可读、可操作且单行不换行。
- 第二行搜索和视图切换在滚动 compact 状态下持续可用。
- 语言菜单键盘和鼠标交互完整。
- 中文、英文与自动语言模式全部正确。
- 无逐帧完整 React 重渲染回归。
- 自动化测试、Lint、TypeScript、Vite 构建和 dist 校验全部通过。
- 独立规格审查和代码质量审查均通过。
