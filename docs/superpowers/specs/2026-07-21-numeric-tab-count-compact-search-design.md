# 纯数字标签计数与紧凑搜索框设计

- 日期：2026-07-21
- 状态：已确认

## 目标

继续压缩 Side Panel 顶部空间：标签总数只显示纯数字，搜索框高度由 40px 降至 36px，同时保持完整可访问语义和现有吸顶、搜索、视图切换行为。

## 标签计数

- 工具栏可见内容只显示 `count` 数值，例如 `41`。
- 不显示“个标签页”或 `tabs` 等可见后缀。
- `title` 保留完整本地化内容：中文 `41 个标签页`，英文 `41 tabs`。
- `aria-label` 使用同一完整本地化内容，屏幕阅读器仍能理解数字含义。
- 数字使用现有计数文字颜色、字重和字号。
- 计数区域改为内容宽度，不再占用旧的 72px 弹性宽度；保持不换行且不可被截成半个数字。
- 移除或改写原先 420/340/300px 下用于长计数文案的 `flex-basis` / `max-width` 压缩规则。

## 搜索框

- `.search-box` 高度由 40px 调整为 36px。
- 搜索行中的列表/分组按钮保持当前 28px。
- 搜索图标保持清晰，输入文字、placeholder、清除按钮垂直居中。
- 可适度缩小搜索框左右 padding，但输入区域必须保持 `min-width: 0` 和可用空间。
- 搜索框的 focus、边框、圆角和 sticky 进度动画保持现有语义。
- 搜索 input 必须保持同一个 DOM 节点，内容、选区和焦点在滚动及视图切换过程中不丢失。

## 非目标

- 不改变标签筛选、语言、脱敏、列表/分组或滚动逻辑。
- 不改变列表行高和列表操作按钮尺寸。
- 不新增翻译键、依赖、权限或用户文案。

## 验收

- 工具栏只可见纯数字计数。
- 计数元素具有完整本地化 `title` 和 `aria-label`。
- 中英文 UI 均只显示数字，但辅助语义分别为对应语言。
- 搜索框 CSS 高度准确为 36px。
- 搜索输入、清除、视图切换和 sticky compact 行为不回归。
- 窄宽度下第一行不换行且计数不被裁切。
- 测试、Lint、TypeScript、生产构建和 dist 校验通过。
