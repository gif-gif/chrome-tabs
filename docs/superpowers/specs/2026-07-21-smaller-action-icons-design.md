# Chrome Tab Manager 小型化操作图标设计

- 日期：2026-07-21
- 状态：已确认

## 目标

进一步降低 Side Panel 工具栏和标签列表操作区的视觉重量，同时保持可访问性、状态辨识和原有业务行为。

## 工具栏标准

- 工具栏图标默认视觉尺寸由 18px 调整为 16px。
- 紧凑按钮点击区域由 32px 调整为 28px。
- 适用范围：筛选、语言、全局脱敏、分组折叠/展开、列表/分组视图按钮。
- 选中筛选的文字、选中背景、tooltip、ARIA 和键盘操作保持不变。
- 第一行高度和 sticky 展开高度同步降低。
- 搜索框和搜索清除按钮不因本次修改丢失可用性；搜索框高度原则上保持现有值，避免输入区过小。

## 标签与分组操作标准

- 标签行、窗口/域名分组标题中的眼睛和关闭图标统一为 15px。
- 按钮点击区域统一为 26px。
- 默认、hover、active 状态不显示填充背景。
- 眼睛按钮默认为中性灰，hover/focus 时仅改变图标颜色。
- 关闭按钮默认为中性灰，hover/focus 时仅变为危险红色。
- 键盘 `:focus-visible` 保留清晰的 outline，不使用背景表达焦点。
- disabled/pending 语义和行为保持不变。
- tooltip、ARIA label、事件隔离、关闭确认和脱敏逻辑保持不变。

## 非目标

- 不修改标签内容排版、favicon 尺寸、行高或搜索业务。
- 不新增依赖、权限或用户文案。
- 不改变语言菜单、滚动收起、筛选和视图切换逻辑。

## 验收

- 工具栏紧凑按钮为 28px，内部 SVG 为 16px。
- 标签及分组眼睛/关闭按钮为 26px，内部 SVG 为 15px。
- 标签及分组操作按钮 hover/active/focus 不出现背景填充。
- 关闭按钮 hover/focus 仍为危险色；其他操作 hover/focus 使用非危险强调色或正文色。
- 键盘焦点轮廓清晰。
- 原功能测试、CSS AST 契约、Lint 和生产构建全部通过。
