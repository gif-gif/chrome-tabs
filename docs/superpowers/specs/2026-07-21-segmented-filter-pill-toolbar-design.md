# 标签页筛选分段胶囊工具栏设计

- 日期：2026-07-21
- 状态：待书面规格确认
- 选定方案：方案 A（统一分段胶囊）

## 目标

优化 Side Panel 第一行工具栏的视觉层级与横向排列：标签数量使用独立浅蓝胶囊；“全部 / 当前 / 活动”作为始终可读的分段筛选控件放入统一浅灰胶囊；语言、全局隐藏、分组折叠、关闭侧边栏等操作继续以独立图标靠右排列。

## 第一行布局

从左到右依次为：

1. 标签数量胶囊。
2. 约 10px 的视觉间距。
3. “全部 / 当前 / 活动”分段筛选胶囊。
4. 可伸缩空白区域。
5. 现有其他操作图标，整体靠右排列。

示意：

```text
[ 41 ]   [ ▣ 全部 | ▢ 当前 | ◉ 活动 ]        🌐  👁  ^  ×
```

右侧操作的实际数量继续由当前列表/分组模式决定，不新增或删除任何功能。

## 标签数量胶囊

- 可见内容继续只显示纯数字，例如 `41`。
- 高度约 24px，最小宽度约 28px，水平内边距约 8px。
- 使用全圆角胶囊造型。
- 浅色模式：浅蓝背景、蓝色文字。
- 深色模式：使用现有深色主题下的强调色与强调色柔和背景。
- 数字使用 12px、较粗字重，并使用 tabular numerals，避免位数变化时视觉跳动。
- 保留完整本地化 `title` 和 `aria-label`：中文如 `41 个标签页`，英文如 `41 tabs`。
- 不恢复“个标签页”或 `tabs` 等可见后缀。

## 分段筛选胶囊

- 三个筛选项共同放入一个浅灰色外层胶囊，而不是三个互相分离的背景块。
- 外层高度约 30px，内边距约 2px，内部间距约 2px，全圆角。
- 三个筛选项始终显示文字，不再使用“仅选中项展开文字、未选中只显示图标”的旧行为。
- 常规宽度下，每项显示“图标 + 短文字”。
- 未选中项：透明背景、灰色图标和文字。
- 选中项：白色背景、蓝色图标和文字，并使用极轻阴影强化当前状态。
- 保留 `aria-pressed`、键盘焦点轮廓、鼠标悬停反馈和现有筛选回调。
- 筛选含义不能只依赖颜色；选中项仍由 `aria-pressed="true"` 表达。

## 中英文文案

### 可见短文案

| 筛选 | 中文 | 英文 |
|---|---|---|
| 全部 | 全部 | All |
| 当前窗口 | 当前 | Current |
| 活动标签 | 活动 | Active |

### 完整辅助文案

按钮的 `title` 和 `aria-label` 使用完整含义：

| 筛选 | 中文 | 英文 |
|---|---|---|
| 全部 | 全部标签页 | All tabs |
| 当前窗口 | 当前窗口 | Current window |
| 活动标签 | 活动标签 | Active tabs |

实现时将可见短文案与完整辅助文案分离为明确的国际化键，避免为了缩短工具栏而影响窗口分组标题、其他区域文案或无障碍名称。

## 右侧操作区

- 语言、全局隐藏、全部折叠/展开、关闭侧边栏等现有图标保持独立按钮样式，不放入筛选胶囊。
- 操作区通过弹性空白靠右排列，与筛选胶囊形成清晰分区。
- 继续使用现有 28px 紧凑按钮尺寸、SVG 图标、tooltip、ARIA 和焦点样式。
- 不改变语言菜单、隐私切换、分组折叠、关闭确认逻辑。

## 窄宽度适配

- 工具栏必须保持单行，不能出现横向滚动，也不能裁切数量数字或筛选文字。
- 在常规 Side Panel 宽度下显示“图标 + 短文字”。
- 在约 340px 以下的极窄宽度，允许只隐藏三个筛选项内部的装饰图标，但必须继续显示 `全部 / 当前 / 活动` 或 `All / Current / Active` 文字。
- 极窄宽度下可同步缩小分段项的水平内边距和数量胶囊与筛选胶囊之间的间距。
- 右侧现有操作不得因本次调整被删除；其行为和可访问名称保持不变。

## 深色模式

- 数量胶囊使用深色主题现有 `--color-accent` 与 `--color-accent-soft`。
- 分段胶囊外层使用深色主题的柔和灰色表面。
- 选中项仍为高对比的浅色/白色表面和蓝色文字，确保当前状态清楚。
- 未选中项保持足够的文字和图标对比度。

## 测试与验收

- 中文可见筛选文字严格为 `全部 / 当前 / 活动`。
- 英文可见筛选文字严格为 `All / Current / Active`。
- 三个按钮始终具有可见短文字，不再仅显示选中项文字。
- 中英文 `title` 和 `aria-label` 使用完整文案。
- 数量胶囊仍只显示数字，并保留完整本地化辅助文案。
- CSS AST 测试验证：
  - 数量胶囊的浅蓝背景、蓝字、全圆角和与筛选区的间距；
  - 筛选组的浅灰胶囊背景、内边距和全圆角；
  - 选中项为白底蓝字；
  - 右侧操作区使用自动外边距或等效弹性布局靠右；
  - 极窄宽度隐藏筛选图标但不隐藏文字。
- 现有筛选行为、sticky 搜索动画、语言、隐私、分组折叠、关闭 Side Panel 和 tab 管理测试不得回归。
- ESLint、TypeScript、Vitest、Vite 生产构建和 dist 校验全部通过。
- 不新增依赖、Chrome 权限或远程资源。

## 非目标

- 不调整搜索行、列表行、分组行或标签操作按钮。
- 不改变筛选语义和过滤逻辑。
- 不改变 Side Panel 的打开、关闭和滚动逻辑。
- 不改变现有工具栏图标顺序，除非当前组件插槽本身按列表/分组模式动态出现或消失。
