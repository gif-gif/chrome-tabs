# Chrome Tabs 搜索框渐进吸顶动画设计

**日期：** 2026-07-21  
**状态：** 已确认

## 目标

优化 Side Panel 上下滚动体验：完整工具栏在页面顶部正常展示；用户向下滚动时，搜索框逐渐移动到固定位置，其他工具元素淡出并收起；用户向上滚动时按滚动位置反向恢复。

## 范围

本次只调整 Side Panel 顶部工具区的滚动展示行为，不修改标签页查询、筛选、分组、隐私、语言切换、关闭操作和 Chrome API 行为。

## 交互设计

### 顶部完整状态

滚动位置为顶部时显示完整工具栏：

- 标签页数量。
- 全局隐私按钮。
- 域名分组模式下的全部展开/折叠按钮。
- 搜索框。
- 标签页筛选控件。
- 语言选择器。
- 列表/域名分组视图切换控件。

### 向下滚动

- 使用前约 `112px` 的滚动距离映射 `0–1` 动画进度。
- 搜索框始终可见并逐渐复位到 Side Panel 顶部。
- 搜索框背景、边框、圆角和阴影平滑过渡到吸顶状态。
- 搜索框之外的工具元素同步：
  - 逐渐降低透明度。
  - 轻微向上移动。
  - 逐渐收起占用高度和间距。
- 动画完成后只保留固定搜索框，使标签列表获得更多垂直空间。

### 向上滚动

动画由实际滚动位置驱动，而不是只判断滚动方向：

- 向上滚动时进度自然降低。
- 搜索框逐渐回到完整工具栏中的原始位置和视觉状态。
- 其他工具元素逐渐展开并淡入。
- 回到顶部时完整恢复。

这种方式允许用户停在中间位置时保持对应的中间动画状态，不会发生突然跳变。

## 技术方案

### DOM 结构

将当前统一固定的 `.sticky-controls` 拆分为：

- 一个保持 `position: sticky; top: 0` 的工具栏容器。
- 搜索框作为始终保留的核心区域。
- 搜索框上方和下方的辅助工具区域作为可淡出、可收起区域。

现有控件的语义角色、无障碍名称和业务事件保持不变。

### 滚动进度

新增一个聚焦于滚动动画的 hook，例如：

```ts
useStickySearchProgress(scrollContainerRef, {
  distance: 112,
})
```

职责：

- 监听 Side Panel 的实际滚动容器。
- 使用 `requestAnimationFrame` 合并高频 scroll 事件。
- 将 `scrollTop / distance` 限制到 `0–1`。
- 组件卸载时取消 animation frame 并清理监听器。
- 只在进度实际变化时更新状态。

App 将动画进度通过 CSS 自定义属性传给工具栏：

```tsx
style={{ '--sticky-search-progress': progress }}
```

为方便测试和无障碍状态识别，可同时暴露：

```tsx
data-compact={progress >= 0.96 ? 'true' : 'false'}
```

### CSS 动画

CSS 使用 `--sticky-search-progress` 控制：

- 辅助工具区域的 `opacity`。
- 辅助工具区域的 `transform`。
- 辅助工具区域的 `max-height`、`margin` 和间距。
- 搜索框的圆角、边框颜色和阴影。
- sticky 工具栏的背景、边框、阴影和 backdrop blur。

动画由滚动位置直接驱动，不使用循环 animation，不新增第三方动画依赖。

## 点击与键盘处理

### 防止透明控件误触

当辅助区域接近完全隐藏时：

- 设置 `pointer-events: none`。
- 对已完全隐藏的区域设置 `aria-hidden="true"`。

恢复显示时重新启用交互并移除隐藏状态。

### 焦点保护

如果键盘焦点位于即将隐藏的辅助工具区域：

- 工具栏暂时保持完整展开，或者将动画进度视为 `0`。
- 不允许一个仍持有焦点的控件变透明或被设为 `aria-hidden`。
- 焦点离开辅助区域后，再根据当前 `scrollTop` 恢复对应动画状态。

搜索框本身始终保留并可输入，不会因滚动而重新挂载、失焦或清空内容。

## 减少动态效果

遵循 `prefers-reduced-motion: reduce`：

- 禁止明显的位移、缩放和渐变动画。
- 允许根据滚动阈值近乎即时切换辅助工具区显示状态。
- 搜索框仍保持吸顶，功能不受影响。

## 状态保持

滚动动画不得重置或改变：

- 搜索关键字。
- 标签页筛选条件。
- 列表/域名分组视图。
- 域名组折叠状态。
- 全局与单标签页隐私状态。
- 当前语言。
- Pending 操作和错误状态。

动画进度属于当前 Side Panel 页面会话状态，不进行本地持久化。

## 国际化

本功能原则上不增加新的用户可见文案。现有中英文：

- 搜索框标签和 placeholder。
- 工具栏 aria-label。
- 筛选、语言、视图和隐私控件文案。

均保持原有翻译机制。若测试或实现增加新文案，必须同时提供 `zh-CN` 和 `en`。

## 响应式布局

- 沿用当前 `420px` 窄面板工具栏断点。
- 完整状态下继续使用现有响应式排列。
- 吸顶完成后只有搜索框，必须在 Side Panel 最窄支持宽度下完整占据可用宽度，不产生水平滚动。

## 测试要求

### Hook 单元测试

覆盖：

- `scrollTop = 0` 时进度为 `0`。
- 中间滚动位置生成正确的 `0–1` 进度。
- 超过动画距离时限制为 `1`。
- 向上滚动时进度降低。
- 高频滚动通过 `requestAnimationFrame` 合并。
- 卸载时清理监听器和未执行的 frame。

### App/组件测试

覆盖：

- 搜索框始终位于 sticky 工具栏中。
- 向下滚动后辅助控件进入隐藏状态，搜索框仍存在且内容不变。
- 向上滚动后辅助控件恢复。
- 完全隐藏时辅助控件不可点击且对无障碍树隐藏。
- 辅助控件持有焦点时不会被隐藏。
- 搜索、筛选、视图、隐私和语言状态不会因滚动变化被重置。
- 中英文界面行为一致。

### CSS 与构建验证

覆盖：

- 使用 sticky 搜索工具栏和滚动进度 CSS 变量。
- 包含 `prefers-reduced-motion` 规则。
- 保留 `420px` 响应式规则。
- 完整运行测试、Lint 和生产构建。

## 非目标

- 不根据滚动速度触发不同动画。
- 不使用 GSAP、Framer Motion 等依赖。
- 不改变 Chrome Side Panel 的宽度或关闭行为。
- 不持久化滚动位置或动画进度。
- 不隐藏搜索框。
