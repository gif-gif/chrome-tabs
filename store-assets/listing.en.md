### Detailed description

```text
Tab Manager lists every open tab in every Chrome window in one compact toolbar popup, so you can find, switch to and tidy tabs without leaving the page you are on.

FIND ANY TAB
• Search tab titles and URLs as you type.
• Filter by all tabs, the current window, or your saved tabs.
• "Locate current tab" scrolls straight to the tab you are on.

THREE WAYS TO VIEW
• List view: tabs grouped by window, current window first.
• Domain view: tabs grouped by website. Subdomains such as docs.google.com and drive.google.com are grouped under google.com.
• Custom groups: create groups like "Work" or "Trip", choose which tabs belong in them, rename, pin and drag to reorder. Groups are kept between sessions.

TIDY UP QUICKLY
• Click a tab to jump to it; close single tabs or a whole group.
• Remove duplicate tabs in a group with one click.
• Sort the tabs in each window by domain, then restore the original order.
• Pin important tabs and groups to the top; save tabs to favorites.

COPY
• Copy a tab's link.
• Copy as Markdown: turns the page's main content into clean Markdown on your device. Site access is requested only the first time you use this button.

PRIVACY FIRST
• Hide titles and URLs for all tabs, a single group or a single tab — handy when sharing your screen.
• Everything happens locally. The extension makes no network requests and sends no browsing data anywhere.

COMFORTABLE TO USE
• Light, dark or follow-the-system appearance.
• English and Simplified Chinese interface; follows your browser language by default.
• Popup closes when it loses focus and never takes space from the web page.

HOW TO USE
1. Click the Tab Manager icon in the Chrome toolbar (pin it from the puzzle-piece menu for one-click access).
2. Type in the search box, or switch between list, domain and custom-group views with the buttons next to it.
3. Hover a tab to show its actions: hide, copy link, copy as Markdown, save, pin, close.

Requires Chrome 141 or later.
```
